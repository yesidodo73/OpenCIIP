# 점검 범위와 결과

OpenCIIP는 주요정보통신기반시설 기술적 취약점 분석·평가 방법 상세가이드의 Unix 서버 U-01부터 U-67까지를 Linux 환경에서 점검합니다.

## 점검 분류

| 프로필 | 범위 |
| --- | --- |
| `all` | 전체 항목 |
| `account` | 계정 관리 |
| `file-directory` | 파일 및 디렉터리 관리 |
| `service` | 서비스 관리 |
| `patch` | 패치 관리 |
| `logging` | 로그 관리 |

프로필이나 항목 코드를 지정하지 않으면 전체 항목을 점검합니다.

```bash
sudo openciip scan
sudo openciip scan --profile account
sudo openciip scan --check U-01,U-02,U-03
```

## 결과 상태

| 화면과 TXT 표시 | JSON 상태 코드 | 의미 |
| --- | --- | --- |
| `양호` | `PASS` | 점검 기준을 충족합니다. |
| `취약` | `FAIL` | 점검 기준을 충족하지 않습니다. |
| `수동 확인 필요` | `UNKNOWN` | 현재 수집한 정보만으로 판단하기 어렵습니다. |
| `확인 실패` | `ERROR` | 권한, 명령 실행 또는 설정 해석 중 오류가 발생했습니다. |
| `해당 없음` | `NOT_APPLICABLE` | 해당 기능이나 서비스가 사용되지 않습니다. |
| `점검하지 않음` | `SKIPPED` | 사용자가 점검에서 제외했습니다. |

배포판별 설정 경로나 지원하는 명령이 달라 판단할 수 없는 경우에는 해당 항목만 `수동 확인 필요`로 표시합니다. 다른 항목의 점검은 계속 진행합니다.

## Linux 지원

읽기 전용 점검은 Linux 전반에서 실행할 수 있습니다. 배포판과 버전에 따라 일부 항목은 `수동 확인 필요` 또는 `해당 없음`으로 표시될 수 있습니다.

다음 amd64 환경에서는 `0.1.0` 버전으로 U-01부터 U-67까지 전체 읽기 전용 점검을 완료했습니다.

| 운영체제 | 버전 | 아키텍처 | 상태 |
| --- | --- | --- | --- |
| Rocky Linux | 9.5 | amd64 | 테스트 완료 |
| Rocky Linux | 9.6 | amd64 | 테스트 완료 |
| Rocky Linux | 9.7 | amd64 | 테스트 완료 |
| Rocky Linux | 9.8 | amd64 | 테스트 완료 |
| Ubuntu | 18.04 LTS | amd64 | 테스트 완료 |
| Ubuntu | 20.04 LTS | amd64 | 테스트 완료 |
| Ubuntu | 22.04 LTS | amd64 | 테스트 완료 |
| Ubuntu | 24.04 LTS | amd64 | 테스트 완료 |
| Ubuntu | 26.04 LTS | amd64 | 테스트 완료 |
| CentOS Linux | 8.5.2111 | amd64 | 테스트 완료 |

전체 점검 완료 여부는 읽기 전용 점검을 기준으로 하며, 자동 조치 지원 여부와는 별개입니다.

위 환경에서는 U-19, U-22, U-29의 자동 조치를 지원합니다. `0.1.0` 버전에서 세 항목의 적용 후 재점검과 실행 전체 롤백, 재부팅 후 실행 전체 롤백을 확인했습니다. 항목별 롤백은 U-22에서 확인했습니다. 다른 항목은 자동 조치 대상이 아닙니다. 실제 시스템에서는 서비스 구성과 사용 방식에 따라 영향이 다를 수 있으므로 적용 전에 변경 계획을 확인하세요.

## 결과 활용

점검 결과는 서버 설정을 확인하기 위한 기술 자료입니다. 조직의 예외 정책, 자산 범위와 보완 통제를 포함한 최종 판단은 별도로 확인하세요.
