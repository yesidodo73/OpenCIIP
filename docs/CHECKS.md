# 점검 범위와 결과

OpenCIIP는 주요정보통신기반시설 기술적 취약점 분석·평가 방법 상세가이드의 Unix 서버 U-01부터 U-67까지를 Linux 환경에서 점검합니다.

## 점검 분류

| 프로필 | 범위 |
| --- | --- |
| `all` | 전체 항목 |
| `account` | 계정 관리 |
| `file-directory` | 파일 및 디렉터리 관리 |
| `service` | 서비스 관리 |
| `patch` | 패치 관리 |
| `logging` | 로그 관리 |

프로필이나 항목 코드를 지정하지 않으면 전체 항목을 점검합니다.

```bash
sudo openciip scan
sudo openciip scan --profile account
sudo openciip scan --check U-01,U-02,U-03
```

## 결과 상태

| 상태 | 의미 |
| --- | --- |
| `PASS` | 점검 기준을 충족합니다. |
| `FAIL` | 점검 기준을 충족하지 않습니다. |
| `UNKNOWN` | 현재 수집한 정보만으로 판단하기 어렵습니다. |
| `ERROR` | 권한, 명령 실행 또는 설정 해석 중 오류가 발생했습니다. |
| `해당 없음` | 해당 기능이나 서비스가 사용되지 않습니다. 내부 상태 코드는 `NOT_APPLICABLE`입니다. |
| `SKIPPED` | 사용자가 점검에서 제외했습니다. |

배포판별 설정 경로나 지원하는 명령이 달라 판단할 수 없는 경우에는 해당 항목만 `UNKNOWN`으로 표시합니다. 다른 항목의 점검은 계속 진행합니다.

## Linux 지원

Linux 공통 설정을 기준으로 점검하며 배포판, 버전과 설치 구성에 따른 차이는 항목별로 처리합니다.

현재 전체 점검을 확인한 환경은 다음과 같습니다.

| 운영체제 | 버전 | 아키텍처 | 상태 |
| --- | --- | --- | --- |
| Rocky Linux | 9.8 | amd64 | 테스트 완료 |

표에 없는 Linux 배포판에서도 점검을 실행할 수 있습니다. 테스트를 완료한 환경과 동일한 결과를 보장한다는 의미는 아니며, 배포판별 차이를 해석하지 못한 항목은 `UNKNOWN`으로 남습니다.

## 결과 활용

점검 결과는 서버 설정을 확인하기 위한 기술 자료입니다. 조직의 예외 정책, 자산 범위와 보완 통제를 포함한 최종 판단은 별도로 확인하세요.
