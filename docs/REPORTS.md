# 보고서와 증적

## 출력 형식

기본 출력은 다음 형식으로 구성됩니다.

- 터미널
- TXT 보고서
- JSON 실행 메타데이터와 항목별 결과
- 선택된 범위의 항목별 TXT 증적

HTML 보고서는 구현하지 않습니다.

## 기본 저장 정책

기본 보고서는 문제가 발견된 항목의 증적만 저장합니다.

사용자가 옵션을 지정하면 모든 항목의 증적을 저장할 수 있어야 합니다.

기본 저장 대상:

- `FAIL`
- `UNKNOWN`
- `ERROR`

선택 저장 대상:

- `PASS`
- `NOT_APPLICABLE`
- `SKIPPED`

## 증적 내용

증적에는 필요에 따라 다음 정보를 포함합니다.

- 실행한 명령
- 명령 인자
- 종료 코드
- stdout
- stderr
- 실행 시간
- 확인한 파일 경로
- 관련 설정 일부
- 줄 번호
- 판정 이유
- 가이드 근거

설정 파일 전체를 기본 저장하지 않습니다.

판정에 필요한 주변 줄만 줄 번호와 함께 저장합니다.

stdout과 stderr는 내부적으로 분리하여 수집합니다.

## 보고서 구조

```text
reports/
└── 2026-07-10_182500_hostname_runid/
    ├── summary.txt
    ├── failures.txt
    ├── metadata.json
    ├── results.json
    └── evidence/
        ├── account/
        │   ├── U-01.txt
        │   └── U-02.txt
        ├── file_directory/
        ├── service/
        ├── patch/
        └── logging/
```

시스템 정보는 `summary.txt`에 포함합니다.

`evidence` 하위 분류는 가이드의 분류 수준까지만 나눕니다.

`metadata.json`은 실행 정보와 상태별 합계를 저장하고, `results.json`은 항목별 전체 판정 결과를 저장합니다. 시간은 RFC 3339 형식으로 기록하며 실행 식별자, 도구 버전, 커밋, 가이드 연도, 규칙 데이터 SHA-256, 대상 OS·버전·아키텍처, 필터, 마스킹 설정, 완료 여부와 종료 코드를 포함합니다. 안전하게 수집할 수 있으면 자동 조치 입력의 동일 호스트·부팅 세션 검증에 사용하는 마스킹된 대상 identity도 메타데이터에 포함합니다.

현재 읽기 전용 점검 보고서에는 자동 조치 실행 기록 파일을 생성하지 않습니다. 조치 상태와 롤백 이력은 고정된 조치 상태 루트의 내구성 저널에서 별도로 관리합니다.

보고서는 먼저 권한이 `0700`인 임시 실행 디렉터리에 작성합니다. 각 파일을 `0600`으로 원자적 교체하고 동기화한 뒤에만 최종 실행 디렉터리명으로 변경합니다. 작성이 중단된 임시 디렉터리를 완성된 보고서로 취급하지 않습니다.

자동 조치 입력으로 다시 읽을 때는 Linux에서 최종 보고서 디렉터리가 조치 실행 사용자 소유의 정확한 `0700`, `metadata.json`과 `results.json`이 같은 사용자 소유의 단일 링크 `0600` 일반 파일인지 다시 확인합니다. `.partial` 디렉터리, 심볼릭 링크, 다른 소유자 또는 완화된 권한의 복사본은 조치 입력으로 사용하지 않습니다.

JSON은 알 수 없는 필드, 중복된 object key, 두 번째 문서와 trailing 데이터를 거부합니다. 규칙 세트 identity는 `sha256:` 뒤의 소문자 64자리 16진수로 검증하고, 도구·플랫폼·호스트·선택 범위·검증 provenance·상태 합계·종료 코드의 내부 정합성이 모두 확인된 보고서만 자동 조치 입력으로 사용합니다.

## 민감정보

다음 값은 기본적으로 마스킹합니다.

- 비밀번호 및 비밀번호 해시
- API 키
- 토큰
- 개인 키
- 세션 식별자
- 인증 쿠키
- SNMP community string
- DB 접속 비밀번호
- 인증 헤더

사용자가 명시적으로 마스킹 해제 옵션을 사용한 경우에만 원문 저장을 허용합니다.

## 권한

```text
디렉터리: 0700
파일: 0600
```

## 출력 형식 호환성

다음 항목도 공개 출력 형식으로 취급합니다.

- TXT 필드명
- 상태 코드
- 보고서 디렉터리 구조
- 파일명 규칙
- JSON 필드명
- 템플릿 스키마
- 명령 종료 코드

공개된 형식을 변경할 때는 기존 호환성을 검토합니다.

불가피한 변경이면 버전 변경과 마이그레이션 내용을 사용자에게 알립니다.
