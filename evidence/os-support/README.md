# OS 지원 검증 기록

이 디렉터리의 JSON은 `0.1.0` 검증 당시 생성된 기록입니다. 당시 항목별 롤백 시험은 U-22만 대상으로 했습니다. U-19와 U-29는 실행 전체 롤백으로 확인했지만, 기존 JSON의 `item_rollback_verified` 값은 세 항목 모두 `true`로 기록되어 있습니다.

따라서 U-19와 U-29의 `0.1.0` 항목별 롤백 여부는 이 JSON만으로 확인할 수 없습니다. 기존 파일은 당시의 해시와 참조 관계를 보존하기 위해 그대로 두었으며, 새 버전의 검증 기록은 실제 시험 결과를 바탕으로 별도로 생성해야 합니다.

Ubuntu 24.04의 기존 기록은 현재 플랫폼 및 조치 정의와 일치하지 않아 현재 검증 명령을 통과하지 못합니다. 과거 점검의 성공 여부와는 별개로, 현재 정의에 대한 검증 기록을 다시 확인해야 합니다.
